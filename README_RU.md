# ИИ Telegram-бот: чат + помощник для контента

## Возможности
- Отвечает на обычные сообщения через Groq API.
- `/post тема` — создаёт пост.
- `/ad товар или услуга` — создаёт рекламный текст.
- `/product товар` — пишет описание товара.
- Кнопочное меню.

Это стартовая версия: платежи, подписки, база пользователей и постоянный хостинг пока не настроены. Бесплатный API может иметь лимиты, которые меняются.

## Безопасность
- Не отправляй Telegram-токен или Groq API-ключ в чат.
- Добавляй ключи только в Secrets / Environment Variables сервиса, где запускаешь код.
- Если токен случайно опубликован, отзови его через BotFather и создай новый.

## Запуск
Требуется Python 3.10+.

1. Установи зависимости: `pip install -r requirements.txt`
2. Установи переменные окружения:
   - `TELEGRAM_BOT_TOKEN` — токен от @BotFather
   - `GROQ_API_KEY` — ключ из https://console.groq.com/
3. Запусти: `python bot.py`

## Google Colab
1. Выполни `!pip install -q -r requirements.txt`
2. В отдельной ячейке:
   ```python
   from getpass import getpass
   import os
   os.environ["TELEGRAM_BOT_TOKEN"] = getpass("Telegram token: ")
   os.environ["GROQ_API_KEY"] = getpass("Groq API key: ")
   ```
3. Помести содержимое `bot.py` в ячейку и выполни.
   Учти: Colab может отключать сессии, и тогда бот остановится.
